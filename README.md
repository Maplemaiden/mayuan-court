# 词句审判庭

华南理工大学马原第 5 组课堂互动：同学各自答题 → 投影汇总总结。

## 玩法

1. 投影打开看板（右上角持续显示二维码），同学扫码答题  
2. 手机点选项后立刻显示对错；答完有正确率与回顾  
3. 看板默认「总览」看六道正确率；点题号进单题条形图 / 揭晓
