# 词句审判庭

华南理工大学马原第 5 组课堂互动：同学各自答题 → 投影汇总总结。

## 玩法

1. 同学扫码，自己连答 6 题（不跟投影切题）  
2. 答完抬头看投影  
3. 讲者在看板上切题、揭晓、一起总结  

## 链接

- 投票：https://maplemaiden.github.io/mayuan-court/vote.html  
- 看板：https://maplemaiden.github.io/mayuan-court/board.html  
- 二维码：`qr-vote.png`

## 课前

1. Supabase 执行过 `schema.sql`  
2. 看板打开 → 可先「清空全部数据」  
3. 同学扫码开答  

课堂结束再清空一次即可。
